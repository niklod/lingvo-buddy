# macOS traps

LingvoBuddy is a sandboxed, ad-hoc signed `LSUIElement` app on macOS 15+, and the dev Macs run macOS 27. Each trap below cost a ticket some time. The file named after it holds the working pattern: reuse it.

## Windows and focus

- **An accessory app cannot activate itself on macOS 27.** `NSApp.activate()` is refused, and a new window opens inactive behind other apps. Every titled window (Settings, Dictionary, onboarding) goes through `ForegroundWindows.show` / `willClose`: it switches to the `.regular` policy while one of our windows is open or minimized. Use it for any new titled window. (`App/Sources/Launch/ForegroundWindows.swift`)
- **Panels stay non-activating.** The card, the tray and quick add are `.nonactivatingPanel` panels: they take key status and keystrokes while the other app stays active. Set the style in `init`, because AppKit ignores a later change. New panels subclass `FloatingPanel`. (`App/Sources/Launch/FloatingPanel.swift`)
- **Panel content must have a finite ideal height.** `FloatingPanel.setContent` sizes the panel with `sizeThatFits` on an unbounded proposal. A view with `maxHeight: .infinity` then reports an endless height, AppKit throws in `setFrame`, and the panel never shows. Snapshots do not catch it. Wrap such a view in `.fixedSize(horizontal: false, vertical: true)`, like the options grid in `QuizCardView`. (`App/Sources/Launch/FloatingPanel.swift`)
- **The card takes key focus only on purpose.** When another of our panels closes, AppKit hands key status to a visible card, and the learner's next key press answers it. `CardPanel` becomes key only through `takeKeyFocus()` (click, ⌥⌘W, a menu command, an icon click). (`App/Sources/Card/CardPanel.swift`)
- **Save and open panels need a window.** Open `NSSavePanel` / `NSOpenPanel` as a sheet on a titled window (Settings), never on a non-activating panel.
- **macOS 26+ paints toolbar glass over SwiftUI headers.** An `NSToolbar`, or a SwiftUI `ScrollView` under a transparent title bar, draws over a custom header. The Dictionary window has no toolbar and hides the top scroll edge effect (`scrollEdgeEffectHidden`).

## Status item

- **Keep `statusItem.menu` nil.** A menu on the status item eats every click, also the click that reopens a waiting card. The icon's action reopens the card or toggles the tray. (`App/Sources/StatusBar/StatusItemController.swift`)
- **Status items live outside the app process.** A click on our own icon also reaches the global mouse monitors that close the tray on outside clicks. See `closeUnlessOnIcon` in `App/Sources/Tray/TrayMenuController.swift`.

## Hotkeys

- **A default global hotkey needs Command or Control.** Sandboxed apps on macOS 15 cannot register Option-only shortcuts. The defaults are ⌥⌘W and ⌥⌘L, through KeyboardShortcuts (Carbon `RegisterEventHotKey`: sandbox-safe, no Accessibility permission).
- Do not watch key events with `NSEvent.addGlobalMonitorForEvents(.keyDown)` or a `CGEventTap`: both need Accessibility or Input Monitoring permission. Global monitors for mouse events need no permission.

## Focus and full screen

- **Focus status needs a restricted entitlement.** `INFocusStatusCenter` works only with `com.apple.developer.usernotifications.communication` and a provisioning profile. An ad-hoc build cannot carry it, and with the entitlement it does not launch. Keep it out of `project.yml`. `SystemFocusStatus` reads the entitlement at runtime and treats Focus as off without it. (`App/Sources/Schedule/FocusStatus.swift`)
- **No public API tells that another app is in full screen.** `FullScreenDetector` compares the frontmost app's window bounds with the screen sizes through `CGWindowListCopyWindowInfo`. This needs no Screen Recording permission while it reads no window names. Private CGS / SkyLight APIs fail App Review.
- **Screen sharing cannot be detected.** "Pause" covers it.

## Sandbox

- The app writes only inside `~/Library/Containers/com.niklod.LingvoBuddy/`. The bundled dictionary opens read-only from the app bundle, so it ships in journal mode DELETE: a WAL file would need a writable folder for `-shm`.
- `App/Info.plist` and `App/LingvoBuddy.entitlements` are generated by XcodeGen from `project.yml`. Edit `project.yml`.
- A Services item without `NSRequiredContext` (even empty) is registered but hidden.
